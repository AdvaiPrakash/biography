# Biography Mobile App

A Flutter mobile application for displaying personal biography and portfolio information.

## Features

- **Profile Header**: Display name, title, and location
- **About Section**: Personal description and background
- **Experience Section**: Professional work history
- **Skills Section**: Technical skills and competencies
- **Responsive Design**: Clean, modern Material Design 3 UI

## Getting Started

### Prerequisites
- Flutter SDK (3.10.3 or higher)
- Dart SDK
- Android Studio / VS Code with Flutter extensions

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd biography
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the application:
   ```bash
   flutter run
   ```

## Customization

To customize the biography information:

1. Open `lib/main.dart`
2. Modify the content in:
   - `ProfileHeader` widget for personal details
   - `AboutSection` widget for personal description
   - `ExperienceSection` widget for work history
   - `SkillsSection` widget for skills
